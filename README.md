## О приложении

**Биток** связывает учеников бильярдных клубов с тренерами. Ученик записывается к тренеру в два касания, видит, как растут его навыки после каждой тренировки, получает медали за турниры и общается с тренером и другими игроками клуба. Тренер ведёт расписание, подтверждает заявки, оценивает учеников и проводит турниры.

Главная идея — **измеримый прогресс**. После каждой тренировки тренер оценивает пять навыков игрока, и ученик видит рост на радарной диаграмме и графиках. Медали, рамки профиля и титулы делают регулярные занятия интереснее.

| | |
|---|---|
| **Для кого** | Ученики и тренеры бильярдных клубов и школ: русский бильярд, пул, снукер, карамболь |
| **Платформа** | iOS 17+ · SwiftUI · дизайн Liquid Glass |
| **Оформление** | Две темы: светлая *Ivory & Oxblood* и тёмная *Midnight Chalk*, по умолчанию «Авто» |
| **Backend** | Микросервисы: NestJS (TypeScript) + Go · Kafka · PostgreSQL · Redis |
| **Статус** | Аналитика утверждена, каркас iOS и backend готов, оплата СБП и магазин заложены на v1.0 |

## Функции

### 🧑‍🎓 Для ученика

- **Запись к тренеру** — выбор тренера, дня в сетке месяца и свободного слота. Повторное нажатие не создаёт дубликат, занятый слот сразу пропадает из списка.
- **Мои записи** — предстоящие и прошедшие тренировки со статусами: ждёт тренера, подтверждена, завершена, отменена.
- **Календарь iOS и напоминания** — тренировка добавляется в системный календарь одной кнопкой; локальное напоминание за 2 часа работает даже без интернета.
- **Прогресс по 5 навыкам** (0–100): стойка и удар, прицеливание, позиционная игра, контроль битка, тактика. Радарная диаграмма «сейчас / месяц назад», графики истории, комментарии и задания тренера.
- **Уровень игрока** — Новичок → Любитель → Продвинутый → Профессионал → Мастер.
- **Турниры и медали** — золото, серебро и бронза за призовые места и **медаль участника** за каждый сыгранный турнир. Статистика: турниры, забитые шары, победы, соперники.
- **Уникализация профиля** — рамки за медали (золотая, серебряная, бронзовая, стальная, «Легенда»), титулы, бейджи, цветовые темы, анимации для топ-достижений.
- **Приватность** — можно скрыть прогресс и достижения от других учеников; тренер видит прогресс своего ученика всегда.

### 🧑‍🏫 Для тренера

- **Календарь** — день, неделя, месяц. Цвет показывает статус записи, у каждой записи — имя и телефон ученика.
- **Заявки** — подтверждение или отклонение, в том числе прямо из push-уведомления.
- **Ученики** — поиск, фильтр «ждут оценки», профиль ученика с радаром навыков и историей.
- **Оценка после тренировки** — пять слайдеров 0–100, комментарий и домашнее задание.
- **Назначение тренировки** — тренер сам ставит ученику время, о котором договорились.
- **Обмен местами** — тренер меняет двух учеников временем (Иван 17:00 ↔ Наталья 18:00) прямо из карточки тренировки в чате; оба получают сообщение.
- **Турниры** — создание, регистрация участников, ввод итогов; медали и достижения начисляются автоматически.

### 🧑‍🏫 Места, цены и группы

- **Места и расписание** — у тренера несколько мест (например, «Флагман» и «Тиджон»), у каждого свои дни и часы. Место можно открыть всем ученикам или только выбранным.
- **Цены** — базовая цена тренера и своя цена для отдельного ученика. Ученик видит только свою.
- **Групповые (игровые) тренировки** — тренер задаёт место, время, число мест и цену; ученики записываются сами.
- **«Предложить другое время»** — третья кнопка на каждой заявке рядом с «Подтвердить» и «Отклонить».

### 📰 Контент

- **Новости и турниры** — публикует тренер, ученик может сразу написать ему, чтобы записаться.
- **Магазин** по категориям: кии, мелки, перчатки, аксессуары, ремонт кия, обслуживание кия.

### 💬 Общее

- **Ученик ↔ ученик** — в чате с игроком клуба кнопка «＋»: «Предложить сыграть» и «Обменяться номерами». Телефоны открываются только после согласия обоих.

- **Чат** с тренером и **«Предложить поиграть»** — приглашение на тренировку или товарищескую партию с кнопками «Принять / Другое время / Нет».
- **Игроки клуба** — поиск партнёра для игры среди учеников своего клуба. Телефоны других учеников не показываются никогда.
- **Контент** — новости тренеров и клуба, видеоуроки, подобранные под слабые навыки ученика.
- **Уведомления** — о заявках, подтверждениях, оценках, новых медалях; тихие часы для некритичных.

### 🔜 Заложено на будущее (v1.0)

- **Оплата через СБП** — QR-код или кнопка «Оплатить через СБП», таймер, возвраты, чеки по 54-ФЗ. Экран уже свёрстан и включается флагом `paymentsEnabled`.
- **Магазин киев и аксессуаров** — с рекомендациями тренера и самовывозом из клуба (флаг `shopEnabled`).

## Быстрый старт

**iOS** (Xcode 16+, приложение работает на демо-данных без backend):

```bash
brew install xcodegen
```

```bash
cd ios && xcodegen generate && open Bitok.xcodeproj
```

**Тестовые учётки** (код из SMS — `1234`, данные общие для всех учёток на одном телефоне):

| Роль | Имя | Телефон |
|---|---|---|
| Тренер | Алексей Воронов | +7 900 000-00-01 |
| Тренер | Вероника Смирнова | +7 900 000-00-03 |
| Ученик | Иван Петров | +7 900 000-00-02 |
| Ученик | Наталья Белова | +7 900 000-00-04 |

**Android** (JDK 17 и Android SDK; готовый APK — в ветке `apk-builds`, ставится на телефон напрямую):

```bash
cd android && ./gradlew assembleDebug
```

**Backend:**

```bash
cd backend && npm install && npm test
```

```bash
cd backend && docker compose -f deploy/docker-compose.yml up --build
```

## Ключевые архитектурные решения

- **Микросервисы по bounded contexts** — Identity, Booking, Progress, Achievement, Messaging, Content, Payment, Shop; у каждого своя база данных.
- **Без двойных бронирований** — оптимистичные блокировки, уникальный индекс на активную бронь, идемпотентность по `Idempotency-Key`.
- **Событийная интеграция** через Kafka с Transactional Outbox: события не теряются и не публикуются «зря».
- **Оплата подключается без изменения ядра** — решение «нужна ли оплата» принимается в одном месте (`PaymentPolicy`), платёжный контур скрыт за портом `PaymentGateway`.
- **Приватность по умолчанию** — телефон ученика видит только его тренер; прогресс и достижения — по настройкам владельца.
