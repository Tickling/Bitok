# Сайт «Биток»

Лендинг-«сцены» для учеников и тренеров: `index.html` (без сборки, шрифты из Google Fonts). Первый экран — мини-игра на столе (canvas), дальше сцены с анимацией телефона.

- Ссылка на группу ВКонтакте — константа `VK_URL` в скрипте внизу `index.html`.
- Форма заявки пока без сервера: собирает текст заявки, который человек копирует и отправляет в группу ВК.
  Когда появится бэкенд, обработчик `submit` нужно направить на API (`POST /leads`).
- Публикация: любой статический хостинг (GitHub Pages, Яндекс Object Storage, Netlify) — достаточно папки `site/`.
