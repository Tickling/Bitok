# Сайт «Биток»

Одна страница `index.html` без сборки (шрифт Onest из Google Fonts, фото встроены). Страница франшизы временно убрана — она сохранена в ветке `site-franchise`.

Порядок: объёмный стол-мини-игра (точка на битке, прицел вдоль кия) → живая карусель с фото →
интерактивный телефон (экраны и цвет школы) → «ПРАКТИКА» по прокрутке → почему камера не заменяет тренера →
вкладки для школ → заявка.

- Ссылка на группу ВКонтакте — константа `VK_URL` внизу `index.html`.
- Форма заявки пока без сервера: собирает текст, который человек отправляет в группу ВК.
- Публикация: любой статический хостинг — достаточно папки `site/`.
